BINGAWEB WEBSITE
================

This version is built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive layouts for desktop, tablet and mobile
- Real photography from Unsplash
- WhatsApp enquiry form

FILES
-----
index.html
css/style.css
js/script.js

IMPORTANT CUSTOMIZATION
-----------------------
1. Search for "BingaWeb" in index.html if you want to change the business name.
2. Replace the placeholder WhatsApp number in js/script.js:
   const WHATSAPP_NUMBER = "233XXXXXXXXX";
   Example:
   const WHATSAPP_NUMBER = "233241234567";
3. Replace hello@bingaweb.com with your real email.
4. Replace the demo portfolio items with your real projects.
5. Update prices whenever you want.

IMAGE NOTE
----------
The site currently uses free-to-use Unsplash photographs loaded from images.unsplash.com.
If you want the site to work fully offline, download your preferred images and put them in an assets folder,
then replace the image URLs in index.html with local paths such as assets/hero.jpg.

HOSTING
-------
Upload:
- index.html
- css/
- js/

to your hosting public folder (for example htdocs/public_html depending on your host).
